# Changelog

## 1.0.0

Initial public release.

- Added an in-game visual HUD editor opened with F7.
- Added drag-and-drop repositioning for supported Valheim UI elements.
- Added exact numeric X/Y position controls.
- Added scaling and rotation controls.
- Added transparency controls for the minimap terrain, player inventory, inventory info, crafting window, and build menu.
- Added a dedicated minimap compositor that preserves explored-map rendering while allowing terrain transparency.
- Added support for the Valheim 1.0 build menu.
- Added support for the Enter-to-type chat window and chat input field.
- Added boss health, center message, top-left message, NPC dialog, and other HUD targets.
- Blocked gameplay mouse-look, camera zoom, and mouse actions while the editor is open.
- Added persistent BepInEx configuration.
- Added one-time optimized UI discovery to avoid periodic gameplay hitches.
- Added a standard top-right X close button.
